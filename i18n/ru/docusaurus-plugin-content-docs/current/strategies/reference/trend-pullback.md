---
title: TrendPullback
---

TrendPullback ждёт откат внутри часового тренда. Две экспоненциальные
скользящие средние задают направление, а индикатор RSI отмечает откат.

## Установка

В папке проекта TradeJS выполните
`npm install --save-exact @tradejs/strategy-trend-pullback@0.1.2`.
Добавьте пакет в [список стратегий](../../getting-started/add-strategy)
в `tradejs.config.ts`.

## Вход и выход

При росте стратегия ждёт, когда RSI пересечёт нижний порог. Вход возможен,
когда более поздняя свеча закроется выше максимума предыдущей. При падении
проверки идут в обратную сторону. Сигнал отменяется, если тренд закончился
или подтверждение не пришло вовремя.

Стоп ставится за крайней точкой отката. Если цена идёт в нужную сторону,
стратегия подтягивает стоп. По умолчанию цель в четыре раза дальше начального
стопа. Позиция может закрыться раньше по стопу, при потере тренда или по времени.

В пакете есть настройки для часовых и 15-минутных входов. В обоих случаях
направление определяется по закрытым часовым свечам.

[Параметры и исходные значения пакета](https://www.npmjs.com/package/@tradejs/strategy-trend-pullback)
