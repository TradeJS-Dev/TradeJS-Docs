---
title: TradingPatterns
---

`@tradejs/strategy-trading-patterns` объединяет Diamond, Flag, Gartley и
HeadAndShoulders в одну стратегию. Пакет устанавливается отдельно от
`@tradejs/base`.

## Установка и интервал

Установите композицию и дочерние пакеты в Project:

```bash
npm install @tradejs/strategy-trading-patterns@0.1.1 @tradejs/strategy-diamond @tradejs/strategy-flag @tradejs/strategy-gartley @tradejs/strategy-head-and-shoulders
```

Добавьте `"@tradejs/strategy-trading-patterns"` в список `strategies`, сохранив
существующие preset, connectors и indicators. Опубликованная версия `0.1.1`
поддерживает только `INTERVAL: "60"`. Исходный код также принимает `"15"`, но
для этого изменения нужна следующая опубликованная версия. Длительность
фигур измеряется свечами, поэтому смена интервала меняет её календарный срок.

## Решения и выходы

Каждый включённый детектор обрабатывает каждую свечу. Если сигналы совпали,
`TRADING_PATTERNS_PRIORITY` выбирает не более одного решения. По умолчанию
порядок равен Diamond, Flag, Gartley, HeadAndShoulders. Досрочный выход по
фигуре запрашивает только тот детектор, который открыл позицию. Стоп и тейки
исполняет общий механизм TradeJS. Фигуры, план риска и контекст поступают
из дочернего пакета.

## Ключи конфигурации

| Группа | Ключи | Назначение |
| --- | --- | --- |
| Интервал | `INTERVAL` | Задаёт поддерживаемый интервал свечей; по умолчанию `60`. |
| Выбор | `TRADING_PATTERNS_PRIORITY` | Задаёт порядок всех четырёх имён без повторов и пропусков. |
| Дочерние правила | `TRADING_PATTERNS.<name>.enable`, `TRADING_PATTERNS.<name>.LONG.*`, `TRADING_PATTERNS.<name>.SHORT.*` | Включают детекторы и задают переключатель и минимальное отношение прибыли к риску по направлениям. Хотя бы один детектор должен быть включён. |
| Общие направления | `LONG.*`, `SHORT.*` | Задают общие переключатели направлений и нижний порог отношения прибыли к риску. По умолчанию порог `0` сохраняет собственные пороги детекторов. |
| Геометрия | `DIAMOND_*`, `FLAG_*`, `GARTLEY_*`, `HEADSHOULDERS_*` | Сохраняют исходные поля, принимаемые установленными дочерними пакетами. |
| AI | `AI_ENABLED`, `AI_MODE`, `MIN_AI_QUALITY` | Управляют необязательным AI-допуском и локальным фильтром композиции. |

По умолчанию включены все четыре детектора, а настройки их направлений
наследуются из пакетов. Например, обратное направление HeadAndShoulders
экспериментальное и по умолчанию отключено. Удалённые фигуры, включая Bat,
отвергаются парсером. При переходе со старой композиции удалите их
переключатели, элементы приоритета и поля геометрии.

Проверяйте композицию как одну стратегию. Нельзя складывать результаты
отдельных детекторов, поскольку приоритет и занятая позиция меняют набор входов.
