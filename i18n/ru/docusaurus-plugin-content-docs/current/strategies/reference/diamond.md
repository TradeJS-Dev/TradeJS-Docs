---
title: 'Diamond'
---

Diamond ищет разворот, когда расширявшийся диапазон цены сужается и цена выходит за его границу.

## Установка

Выполните команду в каталоге проекта TradeJS.

```bash
npm install --save-exact @tradejs/strategy-diamond
```

Добавьте `"@tradejs/strategy-diamond"` в список `strategies` в
`tradejs.config.ts`. Пакет зарегистрирует стратегию `Diamond`.

## Сигнал и выход

Стандартный интервал составляет 15 минут. Фигуру определяют шесть
подтверждённых экстремумов. После падения закрытие выше нисходящей границы
может подтвердить покупку. После роста закрытие ниже восходящей границы может
подтвердить продажу. Параметр `DIAMOND_ENTRY_MODE` задаёт способ подтверждения.
Режим `close_acceptance` по умолчанию ждёт подтверждающего закрытия после пробоя.

Подробности настройки есть в [README пакета](https://github.com/TradeJS-Dev/TradeJS-Strategy-Diamond#readme).
