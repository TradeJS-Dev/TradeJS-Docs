Crab ищет разворот после того, как пять экстремумов цены образуют фигуру XABCD.

## Установка

Выполните команду в каталоге проекта TradeJS.

```bash
npm install --save-exact @tradejs/strategy-crab
```

Добавьте `"@tradejs/strategy-crab"` в список `strategies` в
`tradejs.config.ts`. Пакет зарегистрирует стратегию `Crab`.

## Сигнал и выход

На стандартном интервале 15 минут стратегия ждёт подтверждения последней
точки D. Бычья фигура заканчивается минимумом и даёт сигнал на покупку.
Медвежья заканчивается максимумом и даёт сигнал на продажу. Цель по умолчанию
стоит на восстановлении 61,8% движения A–D от точки D. Стоп находится за D
на расстоянии 10% длины X–A.

Подробности настройки есть в [README пакета](https://github.com/TradeJS-Dev/TradeJS-Strategy-Crab#readme).
