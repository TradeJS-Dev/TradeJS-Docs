---
title: VwapReversion
---

`@tradejs/strategy-vwap-reversion` торгует подтверждённый возврат внутрь полос
дневного VWAP по закрытым свечам. Пакет не входит в `@tradejs/base`.
Версия `0.1.1` опубликована; историческое исследование не доказывает доходность.

## Вход и выход

Объём взвешивает типичную цену свечи `(high + low + close) / 3`. VWAP и
взвешенная дисперсия сбрасываются каждый день UTC. Полосы отстоят на
`VWAP_BAND_MULT` стандартных отклонений. Расчёт по OHLCV приближённый и не
воспроизводит распределение объёма отдельных сделок внутри свечи.

Для LONG закрытие должно оказаться ниже нижней полосы, а отдельная следующая
свеча должна закрыться внутри обеих полос и ниже VWAP. SHORT симметричен.
Отношение направленного движения к сумме движений, Efficiency Ratio, должно
пройти порог и при формировании, и при подтверждении. По умолчанию требуется
разворот цены к VWAP. Расширение полосы вокруг отклонения не подтверждает вход.

Цель равна VWAP свечи подтверждения. Стоп располагается за экстремумом
отклонения с процентным запасом. Оба значения фиксируются при сигнале.
Стоп и тейк исполняет общий механизм TradeJS. Стратегия также запрашивает
выход по сроку удержания, на границе UTC-дня и при внутридневном пропуске
данных. Увеличения открытой позиции нет.

## Установка

```bash
npm install @tradejs/strategy-vwap-reversion@0.1.1
```

Добавьте `"@tradejs/strategy-vwap-reversion"` в список `strategies` вашего
Project, сохранив существующие connectors, indicators и presets.

## Ключи конфигурации

| Группа | Ключи | Назначение |
| --- | --- | --- |
| Исполнение | `INTERVAL`, `BACKTEST_PRICE_MODE`, `BACKTEST_ENTRY_DELAY_BARS` | Принимают `15` минут (по умолчанию) или `60`. Бэктест требует `close` и нулевую задержку. |
| Полосы | `VWAP_BAND_MULT`, `VWAP_RETURN_BAND_MULT`, `VWAP_MIN_VOLUME_BARS` | Задают полосу отклонения, возврата и число свечей с положительным объёмом. По умолчанию `2`, `0` и `8`. |
| Состояние рынка | `VWAP_ER_PERIOD`, `VWAP_MAX_ER` | Задают окно и максимум Efficiency Ratio; по умолчанию `8` и `0.2`. |
| Подтверждение | `VWAP_MAX_EXCURSION_BARS`, `VWAP_REQUIRE_PRICE_REVERSAL`, `VWAP_MIN_SESSION_BARS_LEFT` | Ограничивают ожидание, требуют разворот цены и время до конца дня. По умолчанию `8`, `true` и `1`. |
| Сроки | `VWAP_MAX_HOLD_BARS`, `VWAP_COOLDOWN_BARS` | Ограничивают удержание и паузу после закрытия; по умолчанию `16` и `4` интервала. |
| Риск | `VWAP_STOP_BUFFER_PCT`, `VWAP_MIN_RISK_RATIO`, `VWAP_MAX_COST_SHARE`, `MAX_LOSS_VALUE`, `RISK_FEE_RATE`, `RISK_SLIPPAGE_BPS`, `RISK_MARKET_IMPACT_BPS` | Задают запас стопа, минимальное отношение прибыли к риску после расходов, необязательный предел доли расходов и бюджет позиции. Предел доли расходов `0` отключает это ограничение. |
| Исследовательский фильтр | `VWAP_AI_GATE_ENABLED` | Включает необязательный экспериментальный локальный фильтр; по умолчанию `false`. |

## Данные и перезапуск

Полный день должен начинаться со свечи 00:00 UTC. Загрузка с середины дня,
пропуски и неправильные OHLCV запрещают входы до следующего полного дня.
Нулевой объём отменяет ожидающий вход. Свечи должны быть закрыты, упорядочены
и выровнены по интервалу. Повтор временной метки не обновляет детектор.

Детектор восстанавливается повторением истории. Открытая позиция требует
также сохранённого состояния её сопровождения. Если после перезапуска его
нет, стратегия запрашивает выход `VWAP_UNRESTORED_POSITION`, поскольку возраст
позиции неизвестен. Техническая корректность воспроизведения не доказывает
устойчивость доходности или диверсификацию.
