Это третья глава [пошагового руководства по Pine-стратегии](./pine-strategy-step-by-step).
Связующий код читает значения Pine и преобразует их в решения TradeJS.

Работа делится на два этапа:

1. [Подготовьте входные параметры и чтение значений](./pine-strategy-runtime-setup).
2. [Запустите Pine и верните решение стратегии](./pine-strategy-runtime-decisions).

Так каждый пример остаётся коротким, а вместе две страницы составляют один
файл `core.ts`.

**Назад:** [постройте фигуры для входа](./pine-strategy-figures). **Далее:** [подготовьте входные параметры и чтение значений](./pine-strategy-runtime-setup).
