Начните с одного сервера. Порядок настройки описан в [руководстве по эксплуатации](./production-runbook).

## Single-node вариант

- TradeJS запускает веб-приложение и рассчитывает сигналы для настроенных развёртываний.
- Redis хранит настройки аккаунтов и записи работы приложения. TimescaleDB хранит историю рынка.
- Прокси принимает HTTPS. Redis и PostgreSQL остаются во внутренней сети.
- Сервис ML нужен, только если вы используете модели.

## Multi-node вариант

Сначала измерьте, где не хватает ресурсов. Например, можно вынести базу данных
или ML на отдельный сервер. После переноса проверьте подключение к хранилищам,
доступ к истории и обработку новых свечей.

## Нефункциональные требования

Храните точную версию образа и проверьте [восстановление из резервной копии](./backup-restore).
Состояние после запуска проверяйте по [руководству мониторинга](./monitoring-alerts).
