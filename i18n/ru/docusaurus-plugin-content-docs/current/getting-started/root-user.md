---
title: Локальный пользователь root
---

Команды TradeJS по умолчанию используют `--user root`. В проекте, созданном
через `npx create-tradejs`, страница установки сама создаёт этого локального
пользователя и предлагает выбрать пароль.

Следующие шаги нужны только при ручной настройке существующего проекта или
смене пароля через командную строку.

## Создание или обновление пользователя

```bash
npx @tradejs/cli user-add \
  --user root \
  --password 'StrongPassword123!'
```

Команда хеширует пароль с помощью bcrypt и сохраняет локального пользователя в
Redis. Не добавляйте пароль в скрипты, систему контроля версий, снимки экрана и
общую историю команд.

## Вход и настройка сервисов

1. Откройте страницу входа TradeJS.
2. Войдите как `root` с выбранным паролем.
3. Откройте настройки счёта через шестерёнку в левой панели.
4. Добавьте только нужные параметры: данные биржи, ключ AI-провайдера или
   настройки Telegram.

Секреты хранятся отдельно для каждого пользователя и показываются в
веб-приложении в скрытом виде. Биржевому ключу выдавайте только необходимые
права; разрешение на вывод средств для торговли не требуется.

## Смена пароля

Измените пароль в настройках счёта или выполните:

```bash
npx @tradejs/cli user-add \
  --user root \
  --password 'NewStrongPassword456!'
```

## Диагностика ручной настройки

Если вход не работает, убедитесь, что Redis запущен, команда использовала
нужный экземпляр Redis, а имя пользователя равно `root`. В хранилище находится
хеш, а не исходный пароль.

Для обычной первой установки вернитесь к разделу
[Первый бэктест](./first-backtest). Перед реальной торговлей добавьте нужный
биржевой счёт и перейдите к разделу
[Запуск стратегии в рабочем окружении](./run-strategy-in-production).
