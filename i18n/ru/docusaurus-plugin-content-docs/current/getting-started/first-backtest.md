Бэктест показывает, как стратегия отработала бы на исторических данных.
В этом примере вы проверите [MaStrategy](../strategies/reference/ma-strategy)
на биткоине в веб-приложении. Аккаунт на бирже и API-ключи не нужны.

[Как подготовить бэктест с агентом](../guides/develop-with-an-agent).

## 1. Создайте и запустите проект

Установите Node.js 24 и npm 10 или новее. Запустите Docker и проверьте, что
команда `docker compose version` выводит версию. В папке, где хотите создать
проект, выполните:

```bash
npx create-tradejs
```

Команда создаст папку `tradejs-project`, установит пакеты и запустит приложение
и локальные сервисы. Если браузер не открылся, перейдите по адресу из терминала.
Если шаг завершился ошибкой, откройте [инструкцию по установке](./installation).
Если приложение уже открыто, переходите к следующему шагу.

## 2. Завершите установку

На странице установки задайте пароль для локального пользователя `root`.
TradeJS выполнит вход и откроет главную страницу. Нажмите **Create backtest**.
В бета-версии эта кнопка называется **Run backtest**.

## 3. Запустите бэктест

Выберите **MaStrategy** и настройки **MaStrategy:base**. Укажите Binance,
добавьте только **BTCUSDT** и задайте 15 минут и 30 дней. Нажмите **Start**.

Откройте запуск, чтобы посмотреть ход расчёта. Когда он закончится, посмотрите,
сколько сделок закрылось, какой получился итог и какой была просадка. Сделок может
не быть. Результат зависит от периода, данных и настроек.
[Как читать результат](./understanding-output).

Если хотите проверить другую стратегию, [выберите её в каталоге](../strategies/reference)
и [сохраните настройки для бэктеста](./backtest-config).

## Остановка и повторный запуск

Чтобы остановить приложение, нажмите `Ctrl+C` в терминале, где запущен TradeJS.
Чтобы остановить и локальные сервисы, выполните `npm run infra-down` из папки
`tradejs-project`.

Чтобы открыть приложение снова, перейдите в `tradejs-project` и выполните:

```bash
npm run infra-up
npm run dev
```
