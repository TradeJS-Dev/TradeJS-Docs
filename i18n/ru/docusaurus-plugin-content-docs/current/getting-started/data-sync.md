title: Синхронизация данных
---

TradeJS загружает свечи при запуске обычного бэктеста. Если историю нужно
загрузить заранее, используйте команду ниже.

## Проверка и заполнение пропусков в приложении

Экран **Data coverage** и очередь **Backfill queue** доступны в выпусках, где
включено покрытие данных. В стабильной версии `3.1.28` этих экранов нет.

На совместимом сервере владелец проекта может выбрать набор данных, ряд
и день по UTC, поставить загрузку пропуска в очередь и проверить результат.
Если сервер поддерживает MCP, [покрытие можно проверить через агента](../guides/mcp#data-coverage).

## Обновить свечи из терминала {#1-npx-tradejscli-backtest---updateonly}

Запустите локальные сервисы. В папке проекта выполните команду с уже
сохранёнными настройками бэктеста. В примере обновляются свечи Binance BTCUSDT
с настройками первого бэктеста.

```bash
npm run backtest -- --updateOnly --user root --config MaStrategy:base \
  --connector binance --tickers BTCUSDT --timeframe 15
```

## Перезагрузить свечи при пропусках {#2-npx-tradejscli-continuity}

При обнаружении разрыва `continuity` может удалить сохранённые свечи
выбранного ряда и заново загрузить историю. Используйте команду только если
готовы перезагрузить данные. Пример ограничен рядом BTCUSDT на Binance
с интервалом 15 минут.

```bash
npm exec -- tradejs continuity --user root --timeframe 15 \
  --provider binance --tickers BTCUSDT
```
