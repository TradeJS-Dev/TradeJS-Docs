---
title: Разработка с агентом
description: Дайте агенту документацию TradeJS и задачу, которую он сможет проверить в вашем проекте.
---

Откройте папку проекта в агенте. С её помощью он сможет проверить установленные
пакеты, найти настройки и запустить тесты рядом с кодом.

[Подключите MCP](./mcp), если агенту нужны данные работающего TradeJS.

## Дайте агенту документацию

Отправьте ему [указатель документации](https://docs.tradejs.dev/llms.txt) и статью по задаче.
Для разработки используйте [руководство по TypeScript](../strategies/authoring/typescript-strategy-step-by-step).
Для готовых стратегий правила и настройки собраны в [каталоге](../strategies/reference).

## Запустить исследование

Укажите стратегию, период и рынок. Начать можно с готовой конфигурации.
Для Codex см. [навыки TradeJS для исследований](./codex-strategy-skills).

```text
Исследуй готовую конфигурацию HeadAndShoulders. Сначала изучи предыдущие прогоны.
Возьми только USDT-контракты и историю из локального кэша.
Зафиксируй биржу, тикеры, даты, комиссию и настройки перед запуском.
Раздели историю по времени. Подбери варианты на первом отрезке и проверь
выбранный вариант на отложенном. Покажи число сделок, просадку и результат
после издержек для каждого отрезка. Укажи, где лежит отчёт.
```

## Создать стратегию

Дайте агенту точные условия входа, выхода и отмены сигнала. Пусть он сначала
проверит [публичный API стратегии](../strategies/authoring/typescript-strategy-step-by-step).

```text
Создай отдельную стратегию на TypeScript. После закрытия свечи проверяй,
вышла ли цена выше максимума предыдущих 20 закрытых свечей.
Исключи текущую свечу из диапазона. Добавь отдельные настройки стопа и цели.
Проверь вход, пропуск и нехватку истории. Подключи стратегию к локальному
проекту и запусти короткий бэктест. Покажи код, тесты и результат.
```

## Доработать стратегию

Сначала попросите агента воспроизвести текущее поведение. Затем меняйте одно
правило за раз и сравнивайте с исходным вариантом при тех же условиях.

```text
Подготовь одну доработку HeadAndShoulders. Проверь вариант, где для входа
нужны два закрытия подряд ниже линии шеи. Сохрани текущий
вариант для сравнения. Проверь подтверждение, ложный пробой и истечение
ожидания. Прогони оба варианта на тех же свечах, настройках исполнения
и датах. Покажи, где поведение изменилось, и сохрани отчёт локально.
```

## Запустить один бэктест

Укажите имя стратегии, биржу, инструмент, интервал свечей и даты.
Попросите агента записать настройки и путь к файлу с результатом.
Готовый пример есть в [бэктесте HeadAndShoulders](../strategies/reference/head-and-shoulders#backtest).
