---
title: Коннекторы
---

Коннектор передаёт запросы TradeJS источнику данных или бирже.

Стандартный `basePreset` регистрирует встроенный каталог коннекторов из
`@tradejs/connectors`.

Коннектор может поддерживать:

- историю свечей;
- список торгуемых символов;
- текущие цены;
- позиции;
- постановку ордеров;
- обновление тейк-профита и стоп-лосса.

Пример:

```bash
npx @tradejs/cli backtest --connector bybit
npm exec -- tradejs signals --connector bybit
```

Пользовательский коннектор подключается через `tradejs.config.ts`:

```ts
export default defineConfig(basePreset, {
  connectors: ['./src/plugins/myConnector.plugin.ts'],
});
```

## Объём входа и плечо Bybit

Bybit ограничивает объём входа максимумом для выбранного типа ордера
и округляет его вниз до разрешённого шага. Он не увеличивается ради минимального объёма. Некорректные лимиты
или объём ниже минимума блокируют вход. Защитные выходы продолжают покрывать
полную позицию.

До входа коннектор устанавливает плечо и повторно читает его с биржи.
Запрошенное значение ограничено инструментом и уровнем риска с учётом открытых
позиций и ожидающих ордеров, затем округлено к шагу плеча. Неизвестное состояние
биржи, неподтверждённое значение или неподдерживаемый hedge mode блокируют вход.
Снижение плеча не увеличивает количество и не меняет режим маржи.
Поле `orderLeverage` показывает запрошенное и фактическое плечо и причину
снижения. Поле `orderFailureReason` объясняет отказ во входе.
